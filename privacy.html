Privacy Policy

Last updated: November 8, 2026

Overview

AI Second Brain Backup is a personal-use application that uses rclone to synchronize Markdown notes between Google Drive and a private home server. It is not offered as a public service.

Google Drive Access

The application requests Google Drive access to read, create, update, and synchronize files. The granted permission may cover files accessible to the connected Google account, although the application is configured to operate on a designated personal folder.

Data Storage and Usage

Files are stored in Google Drive and on the owner's private home server. OAuth credentials are stored locally for authentication.

Data is used only for personal file synchronization and backup. It is not sold, used for advertising, or intentionally shared with third parties.

Data Security

Access to the home server and synchronization credentials is restricted to the application owner.

Data Deletion

The owner can delete local copies and backups, remove Google Drive files, and revoke application access through Google Account settings.

Changes

This policy may be updated if the application's functionality or data-handling practices change.
